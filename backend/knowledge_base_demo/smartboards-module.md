# SmartBoards Project Management Module

SmartBoards is CloudStream's comprehensive project management solution that helps teams organize and track their work efficiently.

## Key Features

### Kanban View
The Kanban view is the default view for all tasks in SmartBoards. It provides a visual representation of your workflow with customizable columns that can be tailored to match your team's process.

**Features:**
- Drag-and-drop task management
- Custom column creation
- Color-coded task cards
- Quick filters and search

### Gantt Chart
The Gantt Chart feature provides a timeline view of your projects, showing task dependencies and project schedules at a glance.

**Availability:** This feature is available only on **Pro** and **Enterprise** plans.

**Benefits:**
- Visual project timeline
- Task dependency tracking
- Resource allocation overview
- Milestone tracking

### Automation
SmartBoards includes powerful automation features to reduce manual work and keep your boards organized.

**Auto-Archive:** Tasks can be automatically moved to the "Archive" status after 30 days of inactivity. This helps keep your active boards clean and focused on current work.

**Configuration:** Automation rules can be configured in the board settings under the "Automation" tab.
