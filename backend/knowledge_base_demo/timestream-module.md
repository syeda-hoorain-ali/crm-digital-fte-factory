# TimeStream Time Tracking Module

TimeStream is CloudStream's integrated time tracking solution that makes it easy to track billable hours and monitor project time allocation.

## Tracking Methods

### Chrome Extension
The TimeStream Chrome Extension allows for seamless time tracking directly from your browser.

**Features:**
- One-click time tracking from any browser tab
- Automatic task detection when working in CloudStream
- Background tracking with minimal performance impact
- Sync across all devices

**Installation:** Available in the Chrome Web Store. Search for "TimeStream by CloudStream" or find the link in your account settings.

### Manual Entry
For times when you forget to start the timer or need to add time retroactively, TimeStream supports manual time entry.

**How to Add Time Manually:**
1. Navigate to the "Timesheet" tab in your project
2. Click "Add Time Entry"
3. Select the task, date, and duration
4. Add optional notes about the work performed
5. Mark as billable or non-billable

## Billable vs. Non-Billable Time

Every task in TimeStream includes a toggle to determine whether tracked time should be included in client invoices.

**Billable Time:**
- Automatically included in invoice calculations
- Shown in client-facing reports
- Tracked separately for revenue reporting

**Non-Billable Time:**
- Internal meetings, admin work, training
- Not included in client invoices
- Still tracked for project cost analysis

**Setting Billable Status:** The billable toggle can be set at the task level or adjusted for individual time entries in the timesheet view.
